# Raptor Nest

A survivor-like tower-defense hybrid in the spirit of Beyond All Reason's
raptor mode. Six glowing nests ring your base core. Between waves you get a
calm 60-second build phase; when the wave hits, your Commander fights in
person. Towers extend your build range, so you push the frontier outward
until your guns reach the nests and burn them down.

## How to play

1. **Build phase (60 s):** pick a tower and click to place it inside the blue
   build zones. Every structure extends the zone, so chain towers toward the
   nests. Press **Enter** when ready.
2. **Wave phase:** move the Commander with **WASD**; it fires automatically
   at the nearest raptor (or nest). Towers shoot raptors first, then any
   nest in range.
3. **Loot:** slain raptors drop metal, which is also XP. Level-ups let you
   pick one of three upgrades. Leftover loot is swept up when the wave ends.
4. Waves grow every round; every 4th wave brings a Matriarch.

**Win** by destroying all six nests. **Lose** if the Core or the Commander
falls.

| Tower | Cost | Role |
|---|---|---|
| 1 Light Laser | 60 | cheap, fast beam |
| 2 Heavy Laser | 150 | slow, hard-hitting beam, tough |
| 3 Rocket Battery | 220 | long-range splash, best nest killer |
| 4 Dragon's Teeth | 20 | wall that soaks raptor bites |
| 5 Nano Tower | 120 | repairs nearby structures, larger build radius |

## Controls

| Key | Action |
|---|---|
| WASD / arrows | move the Commander |
| 1-5 + left click | choose and place a tower (build phase) |
| Enter / Space | start the wave early |
| 1-3 or click | pick a level-up upgrade |
| P / Esc | pause |
| M | mute / unmute |

Audio starts after the first key press on the title screen (browser autoplay
rules).

## Development

Requires [mise](https://mise.jdx.dev).

```sh
mise run build   # wasm build into dist/
mise run serve   # build and serve on http://localhost:8080
mise run test    # unit tests for the rules in crates/sim
mise run run     # native build (needs libasound2-dev on Linux)
mise run lint
```

`crates/sim` holds the pure, unit-tested game rules and sound synthesis;
`crates/game` is the macroquad front end.
