Real BAR assets in the survivors games

Design document, revision 2 (review corrections applied). Status: proposal, not implemented. Date: 2026-10-27. BAR source checked: beyond-all-reason/Beyond-All-Reason at commit dab26c9a95782f1c536c0f984ea931e06c0e3beb.

Summary. Most BAR art, sound and music is CC BY-NC-ND 4.0 or "all rights reserved". Those files, and anything made from them, must not go in this public repo or on GitHub Pages. The only clean source of real BAR art is the set of models by Cremuss (CC BY-SA 4.0) rendered with Arm_* textures (CC BY-SA 4.0). At the pinned commit, every sole-Cremuss model is a building; no commander, mobile unit, turret like armllt, or enemy is by Cremuss. So the public tier is Armada structures only. Players, commanders, enemies and turrets stay procedural.
  • Public tier (default, on Pages): top-down sprites of Cremuss Armada structures, with attribution and CC BY-SA notices and an in-game credits screen. Procedural art and sound stay as the fallback.
  • Private tier (cargo feature bar-private, local only): all other BAR assets. Never committed or deployed unless the rights holders give written permission.

Why ND blocks the pipeline

Each conversion step (resize, re-encode, render, sprite sheet) makes an adapted work, which CC BY-NC-ND does not allow to be shared. BAR's LICENSE.md also forbids putting the artwork "in any other game", so a verbatim copy is against the stated intent too. There is no "verbatim only" route.

Attribution plan

  1. One manifest, bar-assets/manifest.toml. Each entry: id, BAR path, BAR commit, author, licence (SPDX), "modified: yes/no", change description.
  2. Generate bar-assets/generated/ATTRIBUTION.md from it. Each line: title, author, source URL (github.com/beyond-all-reason/Beyond-All-Reason/blob/<sha>/<path>), licence link, change note ("rendered top-down, 64 px, team-colour mask extracted").
  3. Put bar-assets/generated/LICENSE (CC BY-SA 4.0) next to the sprites. Rendered sprites, and rendered wrecks (*_dead.s3o), are adaptations and are CC BY-SA 4.0. Embedding them with include_bytes! forms a collection, so the Rust code stays MIT.
  4. Required: an in-game "Credits" screen in each game that uses a sprite, stating author, source, licence and changes (CC BY-SA §3(a), "reasonable manner based on the medium"). A credits.html linked from the site index is extra, not a replacement.
  5. Update each game's assets/LICENSES.md: models are only partly ND; music is not free; CC0/WTFPL exceptions exist; the fallback is all rights reserved.
  6. State: "Not affiliated with or endorsed by Beyond All Reason."

3. Pipeline

Decision: commit generated public assets, cache the raw sources

Recommended: commit the converted public outputs (well under 0.5 MB). Never commit raw BAR files.

  • Pages CI does not need Blender (about 300 MB). Builds stay fast.
  • Reviewers see each sprite in the diff; each file's licence is checked once by a human.
  • The CC BY-SA files and notices live in the source repo, as share-alike requires.

mise tasks

All bar:* tasks live in the root mise.toml. bar-assets/ gets no mise.toml, so the root build-all loop (which builds every directory with both mise.toml and Cargo.toml) does not pick it up.

TaskDoes
bar:fetchgit init; git remote add origin …; git sparse-checkout set for the licence files, units/, objects3d/Units/<unit>.s3o (and <unit>_dead.s3o) for each manifest entry, and unittextures/Arm_color.dds, Arm_normal.dds, Arm_other.dds; git fetch --depth 1 --filter=blob:none origin <sha>; git checkout FETCH_HEAD. (git clone --depth 1 cannot check out a pinned SHA.) No LFS at the pinned commit; if that changes, add git lfs pull --include=<paths>. Output: .cache/bar/<sha>/.
bar:checkList units with git ls-tree -r HEAD (git ls-files in a sparse clone only shows checked-out paths). For each public entry: resolve the exact nested .lua (e.g. units/CorBuildings/…, units/other/evocom/…) that sets that objectname; read customparams.model_author and author (there is no artist field); fail if neither is present, if the author is not exactly Cremuss, or if there is more than one author and the co-author is not in the manifest's written-confirmation list. Parse the .s3o header and fail if an embedded texture name is not Arm_* (untextured renders need an explicit manifest flag). Pin and hash all 14 licence files (root and folder, including objects3d/Units/license.txt and unittextures/license.txt); fail on any change. Any id not passing goes to a manual allowlist decision, not into the build.
bar:renderBlender -b -P tools/render_s3o.py. Blender pinned as an official tarball by URL + SHA-256 in tools/fetch-blender.sh; the S3O importer add-on pinned to a commit that supports that Blender version. Cycles on CPU with fixed seed and sample count (EEVEE fails headless). Orthographic top-down, transparent film, one frame per unit (rotation happens at draw time with draw_texture_ex), 64 px. The team-colour mask is the alpha channel of tex1; extract it into its own sheet. Then oxipng.
bar:attribWrite ATTRIBUTION.md, the in-game credits text and credits.html from the manifest.
bar:publicfetch → check → render → attrib.
bar:privateLocal only. Unitpics (DDS → PNG), sounds (ffmpeg -ac 1 -ar 22050 -c:a libvorbis -q:a 3), music. Writes .cache/bar-private/. Refuses when CI is set (and see the build.rs guard below).
bar:cicargo clippy and cargo test for bar-assets; called from the root ci task, because each game's --workspace lint does not cover path dependencies.

4. Shared asset crate

API (sketch):

pub enum BarUnit { Armmex, Armsolar, Armwin, Armfus, Armlab, Armflak, Armdrag, Armanni, Armsilo, Armrad, /* … structures only */ }
pub enum Source { Public, Private, Procedural }

pub struct Atlas { /* Texture2D base + team mask per unit */ }
impl Atlas {
    pub fn load(units: &[BarUnit]) -> Atlas;   // call inside main, after the macroquad context exists
    pub fn draw(&self, u: BarUnit, pos: Vec2, size: f32, rot: f32, team: Color,
                fallback: impl FnOnce()) -> Source; // fallback = old draw_* fn
}
  • Wiring: each game is its own Cargo workspace, so bar-assets is a path dependency (../../../bar-assets) in each crates/game/Cargo.toml. That changes 15 lockfiles. Add ../bar-assets/** to sources in each game's [tasks.build], or mise skips rebuilds when sprites or the crate change.
  • Loading: Atlas::load uses synchronous Texture2D::from_file_with_format(include_bytes!(…), Some(ImageFormat::Png)) and sets FilterMode explicitly. It cannot be a static/const. No loading screen is needed on this path (async load_texture would need one).
  • Team colour: two draws per unit, base then mask tinted with the team colour (a change; note it in attribution).
  • bar-private guard in bar-assets/build.rs: if CARGO_FEATURE_BAR_PRIVATE and CI are both set, panic; emit cargo:rerun-if-env-changed=CI. build.rs also generates the private include_bytes! list from files that exist in .cache/bar-private/, so a missing cache does not break compilation.
  • Synth: there are 19 synth.rs files and all differ (19 distinct hashes). Share only a small core (wav_bytes, oscillators, envelopes); each game keeps its own sound recipes. This is a real refactor with a per-game listening check.
  • Each game keeps its draw_* functions as the fallback, so units with no clean asset need no code branch.

6. CI changes for Pages

  • pages.yml: no Blender, no BAR fetch; builds from committed bar-assets/generated/. No cache-key change (the cache only holds */target; the mise sources fix is what matters).
  • Guard step scripts/check-no-private.sh: fails if the site contains files not listed as public in the manifest. The build.rs guard blocks bar-private builds in CI.
  • build-site.sh: copy attribution as credits.html, link it from the index (in addition to the in-game credits).
  • bar-assets-verify.yml (manual dispatch): fetch pinned Blender, cache .cache/bar keyed on the BAR SHA, run mise run bar:public, then compare against committed PNGs with a per-pixel tolerance (PNG bytes are not stable across machines), not git diff --exit-code.
  • Root ci calls bar:ci.

8. Commit plan

  1. docs: this design document.
  2. bar-assets: manifest, fetch and check. Root bar:fetch, bar:check; output the passing list. Decision point: expected result is the ~38 Armada structure ids above. Continue only if Dennis accepts "Armada structures only"; otherwise stop here (no-go) and rely on permission requests.
  3. bar-assets: crate skeleton. BarUnit, Atlas with procedural fallback only, build.rs guard, bar:ci.
  4. games: shared synth core. Move wav_bytes and oscillators only; per-game recipes stay. Listen-check each game.
  5. bar-assets: render pipeline. render_s3o.py, pinned Blender and add-on, bar:render.
  6. bar-assets: first sprites + attribution. armmex, armsolar, armwin, armfus, armmstor, armrad (and other passing structures); LICENSE, ATTRIBUTION.md.
  7. tech-tree-tower: use Atlas as the pilot, with in-game credits; check size and look.
  8. games: use Atlas in the other games that have S entries (11), add ../bar-assets/** to sources in all 15.
  9. licences: update the 15 assets/LICENSES.md; in-game credits screens.
  10. ci: site guard, credits page, verify workflow with tolerance compare.
  11. bar-assets: private tier (bar-private, bar:private).
